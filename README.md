# Vamshi Krishna Keerthi — V7 Intelligence Portfolio

A premium, interactive Data + AI portfolio designed as a product interface rather than a conventional resume site.

## V7 features
- Intelligence-style hero with interactive capability nodes
- Portfolio Copilot with a curated local knowledge base
- Evidence, workflow, and developer-terminal views
- Analytics Command Center with synthetic healthcare/banking/AI demonstrations
- SQL Lab with simulated query execution
- Data Quality Engine
- AI Validation workflow
- Independent synthetic projects: CareLens, RiskPulse, InsightGuard
- Built projects: Telugu AI Tutor and AI Intrusion Detection
- Recruiter View, command palette, dark/light mode, responsive layout
- Resume and LinkedIn CTAs

## Data integrity
Employment history and resume-supported metrics are presented as professional experience. Independent demonstration projects and dashboard data are explicitly labeled synthetic/portfolio simulations and should not be interpreted as employer work.

## Run locally
Open `index.html` directly in a browser, or serve the folder with a local HTTP server.

## Deploy
The site is static and can be deployed to GitHub Pages, Vercel, Netlify, or similar static hosting.
